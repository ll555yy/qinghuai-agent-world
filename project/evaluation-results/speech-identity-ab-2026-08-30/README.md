## 身份一致性

两组共 8 次真实 SpeechGeneration 均满足：

- `activeParticipants` 包含当前会话的正确 Actor ID、姓名和类型；
- 可见原始消息均带 `authorName`；
- `addressedActorIds` 全部属于当前参与者；
- 林慧兰、沈星遥、陈月、周慎之没有被互相错认；
- 本轮没有触发校正重试，说明模型第一次输出即通过名单校验。

这是正向证据，但不能证明模型永远如实声明正文对象；仍需增加包含错误称呼、缺席人物和参与者切换的对抗样本。

## 语气对比

### 沈星遥：明显改善

基线结尾是“……不知道……你们觉得这样可以吗？”，存在连续犹豫和泛化征询。动态版本改为“不过每个人的故事我都会先征得本人同意才会记录的”，保留轻软语气，同时给出符合边界的具体条件，角色辨识度更高。

### 周慎之：明显改善

动态版本比基线更短、更直接：“我的底线只有一条……”，更符合惜字如金、划清边界的表达方式，信息没有明显损失。

### 林慧兰：轻微改善

动态版本保留老话、循序渐进和给他人表达空间，符合人设；但仍偏长，依旧带有会议方案总结感，示例尚未充分压低任务摘要式表达。

### 陈月：自然度提升，但出现事实风险

动态版本的“我跟你说”“这事儿”等口语节奏更贴近角色，也把行动说得更具体；但新增“我已经攒了不少器械和手册了”，当前上下文没有该事实证据。这属于不应由风格示例诱发的完成状态或资源声明，事实一致性弱于基线。

## 结论

首轮结果支持“动态示例能增强角色语气”，尤其对短句型、边界清楚的角色更有效；但还不能直接作为上线通过结论：

1. 为林慧兰补充更短、非会议总结式的推进示例。
2. 调整陈月示例或 SpeechGeneration 规则：没有当前上下文证据时，不得声称已经准备、已经拥有或已经完成具体资源与行动。
3. 扩展到多 seed 盲评，并加入错误称呼、缺席人物、同名误导和参与者切换的身份对抗集。
4. 分开统计生成请求和 embedding 成本；本次两组模型调用次数不同，不能用总 token 直接推断单次成本变化。
