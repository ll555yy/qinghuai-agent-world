# 可见体验正式实施验收

日期：2026-08-22

## 1. 交付结果

- 五名 NPC 已各自具备 neutral / speaking / tense 三态，采用统一的 `1536×1024` 三帧 sprite sheet；玩家使用低信息量中性头像。
- 慎之旧书店正式俯视背景已接入 Phaser，保留原坐标协议、右键命中、聊天圈和中央操作空间。
- 场景气泡已升级为 Actor 独立 FIFO：两行截断、完整内容仍在 ChatPanel、时长上下限、边缘内收、邻近说话者上移避让、卸载清理和 reduced-motion。
- 邀请、接受、拒绝、加入、离开、发言和思考使用不同气泡语义；发言临时切 speaking，拒绝切 tense，结束后恢复快照状态。
- 时间氛围只从公开 `worldTime` 派生：16:00 金色、17:00 停止新聊天提示、17:50 倒计时、18:00 日终遮罩。
- 人物公开卡和聊天面板复用正式头像，没有渲染秘密、Goal、Memory、关系值或模型推理。

## 2. 正式生成提示词组

人物母版：生成中国当代叙事游戏用三帧横向人物表，三帧为同一成年人，依次 neutral / speaking / tense；固定脸型、衣装、裁切和左前方柔光；使用温暖旧纸绘本与简化半写实成人比例；统一深褐背景；禁止文字、水印、品牌和秘密暗示。每名人物再追加资产清单中登记的年龄、公开身份、服装主色与克制状态描述。

玩家母版：年轻中国成年人、中性呈现、普通米色外衫、平静专注；不暗示性别、职业、性格和来历。

场景母版：青槐巷慎之旧书店，高位斜俯视、无人无字；包含右下入口、书架走道、右上柜台与修书台、中央长桌、窗边、文社位置、健康角预留和西北受潮角；暖木、旧纸、墨绿、低饱和灯橙；中央行动区留白，不显示古籍秘密。

完整逐资产提示词摘要、生成方式、尺寸和 SHA-256 见 `VISUAL_ASSET_MANIFEST.md`。

## 5. 体积

- 原前端世界 chunk：gzip 约 326 KB；本版为 328.68 KB，增加约 2.7 KB，没有引入新 UI 框架。
- 五张 NPC 状态表和场景从原始 PNG 压缩为 JPEG；玩家头像因 Phaser/Chromium 解码稳定性保留 PNG。正式运行资产合计约 3.76 MiB，运行时不加载样稿。
- 图片通过 `public` 静态 URL 加载，没有进入 TypeScript/base64；五张确认样稿仍留作审查证据，不参与资产映射。

## 6. 已知限制

- 第一版使用三帧表情切换，不是骨骼动画；说话口型不逐字同步。
- 角色在地图中仍是头像式棋子，不是全身行走 sprite；移动只解释权威坐标变化。
- 场景是单张背景，Day2 漏雨、Day5 受潮暂由公共事件和气泡表达，没有独立破损贴图。
- Phaser chunk 仍超过 Vite 默认 500 KB 警告阈值；它已由路由 lazy-load，第一版不为此引入额外框架或复杂拆包。
