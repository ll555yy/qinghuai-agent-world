# 60—180 秒公开演示录制说明

本说明用于录制可公开展示的本地演示。只录浏览器公开 UI，不展示终端环境变量、`.env`、数据库连接串、Prompt、私有 Goal、Memory、coreSecrets 或调试 Trace。

## 录制前

1. 使用测试或本地数据库，不连接生产数据。
2. 从空白或专用演示 Run 开始；浏览器缩放保持 100%。
3. 启动 PostgreSQL、迁移、FastAPI 和前端，确认页面没有控制台错误。
4. 关闭终端、密码管理器、通知和其他可能出现隐私信息的窗口。
5. 建议使用 1440×900 或 1280×720、30 FPS，录制 90—120 秒。

## 推荐镜头

| 时间 | 操作 | 要说明的工程点 |
|---:|---|---|
| 0—15 秒 | 展示前情提要并选择“青槐文社”任务 | 玩家目标是公开选择，不读取 NPC 私有状态 |
| 15—35 秒 | 进入书店，观察 NPC 自主行动和聊天圈 | Phaser 只渲染 FastAPI/WebSocket 的权威公开投影 |
| 35—65 秒 | 右键 NPC、发起邀请并发送一句公开问题 | 邀请和聊天经过真实 RunService/LangGraph，而非前端伪造 |
| 65—90 秒 | 展示 NPC 回复与事件序号，刷新浏览器 | 消息落 PostgreSQL；刷新后依靠快照与 `afterSeq` 恢复 |
| 90—115 秒 | 推进至日终或展示日终测试片段 | 17:00/18:00 边界与会话关闭由后端权威规则执行 |
| 115—135 秒 | 切到 README 的 canonical 指标 | 说明 47 Case、预注册全分母、检索留出集和 Judge advisory 边界 |

## 旁白要点

- “这是一个 NPC 自主推进的七日聊天世界，不是固定对话树。”
- “Agent 可以提出行动和台词，但不能直接改时间、参与者、Goal 或结局。”
- “Memory 检索同时使用结构化过滤、关键词、向量和有限 Graph 扩展，并且每一步重新检查 owner。”
- “固定自动策略只证明路线可达；真实玩家发现率需要另行试玩，项目不会用 Agent 代替人工样本。”
- “LLM Judge 在人工双标和校准通过前保持 advisory，安全硬门由确定性规则负责。”

## 发布前检查

- 画面中没有终端、Key、密码、数据库 URL、Prompt 或私有调试面板。
- 没有真实用户聊天或未经同意的姓名、头像、声音。
- 只引用 `FINAL_INTERVIEW_READINESS_ACCEPTANCE.md` 中已由 canonical JSON 证明的数字。
- 视频长度在 60—180 秒；若不提交视频文件，本说明本身提供可复现录制路径。
